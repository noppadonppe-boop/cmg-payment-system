✨ ฟีเจอร์ใหม่
───────────────────────────────────────────────────────────────

1. MasterAdmin Role (สิทธิ์สูงสุด)
   ✅ เข้าถึงได้ทุกฟังก์ชันในระบบ
   ✅ จัดการ Projects, Payments, Change Orders
   ✅ จัดการ Users (อนุมัติ, เปลี่ยน role, ลบ)
   ✅ Badge สีพิเศษ (gradient purple-pink)

2. ระบบ Realtime แบบเต็มรูปแบบ
   ✅ เปลี่ยน role → เมนูเปลี่ยนทันที (ไม่ต้อง refresh)
   ✅ สร้าง project → ทุกคนเห็นทันที
   ✅ อนุมัติ payment → สถานะเปลี่ยนทันที
   ✅ สร้าง COR/COA → ทุกคนเห็นทันที
   ✅ อัปเดต bond → ทุกคนเห็นทันที

🔐 สิทธิ์ของ MasterAdmin
───────────────────────────────────────────────────────────────
✅ จัดการ Projects (สร้าง/แก้ไข/ลบ)
✅ อนุมัติ Payments
✅ แปลง COR เป็น COA
✅ อัปเดต Bond Status
✅ สร้าง Payment Claims
✅ เห็น Projects ทั้งหมด (ไม่จำกัดเฉพาะที่ assign)
✅ จัดการ Users (อนุมัติ/เปลี่ยน role/ลบ)
✅ ลบ Projects, Payments, Change Orders

📋 วิธีกำหนด MasterAdmin
───────────────────────────────────────────────────────────────
1. Login ด้วย Admin หรือ SuperAdmin
2. ไปที่ User Management (คลิกไอคอน Shield หรือเลือกจากเมนู)
3. เลือก user ที่ต้องการ
4. คลิกปุ่ม "แก้ไข"
5. เลือก role "MasterAdmin" (อยู่บนสุดของรายการ)
6. คลิก "บันทึก"
7. ✅ เสร็จ! User ได้รับสิทธิ์ทันที

🧪 วิธีทดสอบ Realtime
───────────────────────────────────────────────────────────────

ทดสอบการเปลี่ยน Role:
1. เปิด browser 2 tabs
2. Tab 1: Login ด้วย Admin
3. Tab 2: Login ด้วย User ธรรมดา
4. Tab 1: เปลี่ยน role ของ user ใน Tab 2
5. ✅ Tab 2 จะเห็นเมนูเปลี่ยนทันที (ไม่ต้อง refresh)

ทดสอบการสร้าง Project:
1. เปิด browser 2 tabs
2. Login ด้วย user ต่างกัน
3. ทั้ง 2 tabs เปิดหน้า Projects
4. Tab 1: สร้าง project ใหม่
5. ✅ Tab 2 จะเห็น project ใหม่ทันที

ทดสอบการอนุมัติ Payment:
1. เปิด browser 2 tabs
2. Tab 1: Login ด้วย PM
3. Tab 2: Login ด้วย QsEng
4. ทั้ง 2 tabs เปิดหน้า Payments
5. Tab 1: อนุมัติ payment
6. ✅ Tab 2 จะเห็นสถานะเปลี่ยนทันที

⚠️ ข้อควรระวัง
───────────────────────────────────────────────────────────────
⚠️ MasterAdmin มีสิทธิ์สูงสุด - ให้เฉพาะคนที่ไว้วางใจเท่านั้น
⚠️ MasterAdmin สามารถลบ users, projects, payments ได้
⚠️ ควรทดสอบในสภาพแวดล้อมทดสอบก่อน
⚠️ ควรติดตาม Firestore usage ใน Firebase Console

🐛 แก้ไขปัญหา
───────────────────────────────────────────────────────────────

ปัญหา: ไม่เห็นการเปลี่ยนแปลงทันที
แก้ไข:
  1. ตรวจสอบ internet connection
  2. ดู console มี error หรือไม่
  3. ลอง refresh หน้าเว็บ
  4. ลอง logout และ login ใหม่

ปัญหา: MasterAdmin ไม่เห็นปุ่มบางอย่าง
แก้ไข:
  1. ตรวจสอบว่า role ถูกบันทึกใน Firestore แล้ว
  2. ลอง logout และ login ใหม่
  3. ตรวจสอบ console มี error หรือไม่

ปัญหา: Realtime ไม่ทำงาน
แก้ไข:
  1. ตรวจสอบ internet connection
  2. ตรวจสอบ Firestore rules
  3. ตรวจสอบ Firebase project configuration
  4. ดู console logs
